# Branding

Images used by the manifest builder (`lds-engine builder`), set in `lds_engine.yml` under `builder:`.

| File | What | Source |
|---|---|---|
| `onelondon.png` | OneLondon logo (colour, transparent, 1080 × 318), shown in the band under the NHS header | https://onelondon.online/wp-content/uploads/2022/08/Logo-3.png |

The OneLondon logo is OneLondon's own. onelondon.online's terms exclude the logo from free reuse,
so use it only for OneLondon's services. Replace it with a master file (ideally SVG) from the
OneLondon communications team when one is available, and update `builder.partner_logo`.
